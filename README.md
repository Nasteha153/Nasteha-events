# 🎉 Event Management System

A full-stack **ReactJS Event Management System** with **Venue Decoration Planning**.
The platform allows users to discover and manage events, register for events, create events, and plan venue decorations using inspiration images and decoration preferences.

This project was developed as a **ReactJS Full-Stack Final Project** using modern frontend technologies and Supabase as the backend.

---

## 📌 Project Overview

The **Event Management System** is designed to make event organization easier by bringing event management and venue decoration planning into one platform.

Users can:

* Browse available events
* View detailed event information
* Register for events
* Create and manage their own events
* Plan venue decorations
* Upload decoration inspiration images
* Specify preferred colors and decoration types
* Manage their profile
* Track their event registrations and decoration plans

The application uses **Supabase Authentication and Database** for backend functionality and **React Context API + Reducer** for state management.

---

## 🎯 Project Goals

The main goals of this project are to:

* Build a real-world full-stack React application
* Practice React component architecture
* Implement authentication and authorization
* Work with a real backend using Supabase
* Implement CRUD operations
* Use Context API and Reducer for global state management
* Create a responsive UI using TailwindCSS
* Implement client-side routing with React Router
* Provide a practical event management experience
* Add venue decoration planning functionality
